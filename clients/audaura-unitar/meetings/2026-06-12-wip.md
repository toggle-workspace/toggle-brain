## 1. CAPI / Funnel Data Gap

- CAPI (Conversions API) connected to Salesforce but only capturing top-of-funnel validation events — **not full funnel**
- **Root cause:** Salesforce Sales Cloud overwrites lead status rather than storing history; each stage (new → appointment → application → enrolled) replaces the previous
- Client is on Marketing Cloud, which compounds the issue
- Current lead-to-enrollment conversion: **7.9% YTD** — 92.1% of funnel data is invisible to ad engines
- CAPI is only "learning" from the validated lead signal, not from appointment, disengagement, application, or enrollment stages
- **Workaround identified:** Data Warehouse already takes daily snapshots of lead status
  - Need to confirm whether SQL can link directly to it, and whether historical data is recoverable
  - If not, no look-back possible — data from ~November onwards affected
