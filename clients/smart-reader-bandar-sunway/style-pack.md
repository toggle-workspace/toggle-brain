# Smart Reader Kids Bandar Sunway — Style Pack

> Base: `prompts/style-packs/toggle-default.md`. This file overrides only what differs.

## Voice overrides
- **Tone:** Plain, simple, direct — grade-4 readability. The owner is non-marketing-savvy and allergic to agency jargon and overpromising. Short sentences, common words, no fluff.
- **Words we use for this client:** "sign-ups" / "enrolments" (his goal word), "parent messages" (not "leads / enquiries"), "WhatsApp chat", "government-approved", "free trial week".
- **Words to avoid:** funnel, channel, optimise, retainer, pass-through, blended, intent, CPL/CPA, "engine", brand-building — and anything that sounds like a guaranteed promise.
- **Reference to brand voice doc (Drive link):** TBD

## Visual overrides
- **Primary colors / typography:** Toggle proposal system (Inter Tight, Toggle blue) — see `01-strategy/proposal-2026-06-30.html`. No Smart Reader brand kit on file yet.
- **Logo usage rules:** Smart Reader Kids® — single Bandar Sunway branch; do not imply we represent the franchisor / HQ.
- **Reference images:** none yet

## Platform tone
- **Meta (Facebook / Instagram):** click-to-WhatsApp only — no landing pages, no lead forms. Three angles: Close & Safe · Free Trial Week · Ready for School.
- **Google:** local-intent search, click-to-call + click-to-WhatsApp.
- **TikTok:** free-credit test only; never argue against his "TikTok doesn't work for education" view.
- **LinkedIn / Other:** n/a

## Examples of "yes / no"
- ✓ This works: "Try a full week, free. See if your child loves it before you pay one ringgit."
- ✗ This doesn't: jargon, guaranteed cost-per-enrolment promises, anything that re-opens the TikTok / landing-page / lead-form debates.
