## What the prep deck covers

For ij-solutions (Epic Clone), SolDevelo (QAlity Plus) and codefortynine (Deep Clone), the deck covers:

- a competitor comparison table for each focus app
- each vendor's top 3 apps by installs
- the work we have done and the next moves, each with an owner
- Julian's market research (2 November 2026) applied to each client
- a first draft of the six-step playbook
- eight open questions for the call
