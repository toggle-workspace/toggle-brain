# Toggle Bespoke — AI-Literacy Trainings

Deliverables for the TikTok x Toggle onboarding event and the Toggle Bespoke AI-literacy curriculum. Each file is self-contained HTML, theme-aware, styled with Material 3 (seeded on Toggle blue).

## Files
- `onboarding-event-plan.html` — internal plan for the TikTok x Toggle SME onboarding event (concept, the deal, agenda, 7 decisions, roles, 2-month sprint).
- `workshop-playbook.html` — session-by-session run-book for the event.
- `curriculum-pathways.html` — the AI-literacy curriculum map: an 18-lesson library, five learning pathways, and a crossover matrix. The most critical lessons are starred, with AI-5 Agentic AI and Claude Code emphasized.
- `ai-literacy-m1.html` — Module AI-1, the locked lesson template, with the ELI 15/20/25/30 reading-level toggle.

## Notes
- The lesson template is locked to Material 3 with the ELI reading-level toggle. Depth inside a lesson is set by the toggle; pathways set which lessons and in what order.
- Open decisions: Bespoke pricing (Viknesh), final module count, whether Claude Code is its own lesson or stays as AI-5, and whether to add a Performance-Marketing-with-AI or eCommerce pathway.
