# competitive-intel — iterations

## v1 → v2
- v1 was a SWOT-template clone. **Critique:** SWOT outputs are decoration, not decisions. A founder needs to know "build vs not", not "their strengths and weaknesses."
- **v2 change:** reframed around a decision the user is about to make; removed SWOT scaffolding.

## v2 → v3
- v2 was honest but flat. It didn't push back when the user asked for "research" without a real decision. It also under-weighted source quality (treated landing-page claims as facts).
- **v3 changes:**
  - Step 1 forces decision-naming before any research.
  - "They say vs verified" distinction — landing-page claims are not evidence.
  - "If [X] is true, then [Y]" framing for load-bearing-but-unverified facts.
  - Escalation rule: if the decision is irreversible, GAPS becomes the headline.
  - Refusal to write flattering briefs without evidence.
  - For market-existence briefs: demand-side evidence beats supply-side.
