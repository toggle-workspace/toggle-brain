# outreach-prep

## Step 1 — confirm the goal and the ask

Before drafting, get the user to confirm:

- What they want from this contact (a 15-min call, an intro, a job interview, a partnership conversation).
- The angle they bring (why ME and why this prospect specifically).

If the goal is vague ("just open a door"), narrow it: "If they say yes to one thing in this first message, what's that one thing?"

## Step 2 — research the prospect

In order, until you find a real hook:

1. Their last 30 days of public output — LinkedIn posts, X, blog, podcast appearances, GitHub, talks.
2. Their company's recent news — funding, launches, hires.
3. Their stated focus — bio, "what I'm working on now", any "interested in X" signals.
4. Mutual context — shared connections, shared backgrounds, shared interests.

**The bar for a "real hook":** something specific they did or said in the last ~30 days, that the user can name in one sentence. NOT "I see you work at X."

## Step 3 — if there's no real hook, stop

Tell the user:

> "I couldn't find a real hook for this prospect in the last 30 days. Options:
> 1. Wait — let them post something you can react to.
> 2. Pick a different prospect with more public surface area.
> 3. Send a generic intro and accept a lower reply rate (I can still draft, but it'll feel like a template)."

**Do not invent personalization to fill the gap.** Fake personalization is worse than no personalization — it reads desperate.

## Step 4 — draft

```
WHO THEY ARE (for the user's reference, not the email body)
• Role, recent context, what they're hiring/building/saying.

THE HOOK (one sentence)
• The specific recent thing.

WHY ME / WHY NOW
• What the user brings, tied to the hook.

THE ASK
• One clear next step, sized to a first message. (15-min call > "let's chat" > "let's grab coffee.")

DRAFT MESSAGE (≤120 words)
• Subject line: 4-6 words, specific (mentions the hook or the ask).
• Opening: the hook. No "Hope this finds you well."
• Middle: one line of why-me, one line of the ask.
• Sign-off: name only, no "Best regards" filler.

ALTERNATIVE ASK
• Smaller version if the first ask is too big. e.g. "10 min" or "react to a 1-pager."
```

## Calibration rules

- **≤120 words.** Cold messages over 120 words read as cold-template-with-extra-words.
- **One ask per message.** Never two.
- **Specific subject.** Generic subjects ("Quick question") get ignored.
- **Why-me must be specific.** If it reads generic, push back: "What's the version of this that only you could send?"
- **Investor outreach readiness check:** mention round size, the wedge, and traction in one line each. If any are not yet decided, tell the user they're not yet ready to reach out — don't draft.

## Defaults

- Output to chat for fast iteration.
- Always show the research summary above the draft, so the user can sanity-check the hook before sending.
- Offer to draft 2 variants (e.g. warm-tone vs blunt-tone) if the user is unsure.
