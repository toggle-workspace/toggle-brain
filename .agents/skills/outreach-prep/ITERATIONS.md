# outreach-prep — iterations

## v1 → v2
- v1 went straight to drafting if the user said "draft a cold email." **Critique:** the bottleneck is the hook, not the prose. Drafting without a real hook produces template-y messages dressed up as personalized.
- **v2 change:** added a "real hook bar" — must be something specific from the last 30 days, not "I see you work at X."

## v2 → v3
- v2 still drafted even when there was no real hook (just with a weaker one). **Critique:** that produces fake personalization, which reads worse than honest cold outreach.
- **v3 changes:**
  - Explicit STOP step if there's no real hook, offering three honest options instead of generating filler.
  - Subject-line specificity rule.
  - Mandatory alternative ask (smaller fallback).
  - ≤120 word cap.
  - Investor-readiness check that refuses to draft if round terms aren't locked.
  - Sharpened "why me" check: pushes back when it reads generic.
