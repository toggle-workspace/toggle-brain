# account-brief — iterations

## v1 → v2
- v1 had a single 12-section skeleton for any meeting type. **Critique:** too long for a founder to scan; pre- and post-meeting are different jobs and were mushed together.
- **v2 change:** split into two explicit modes (pre / post), each with its own ≤6-section skeleton.

## v2 → v3
- v2 didn't say what to do when sources are sparse (a solo founder often only has LinkedIn + an email thread). It also implicitly assumed an enterprise CRM was wired up.
- **v3 changes:**
  - Confidence label at the top of every brief.
  - Explicit "degrade gracefully" rule — silently check MCP tool list before reaching for connected tools.
  - Named GAPS section to surface what's missing rather than paper over it.
  - Load-bearing assumption check before finalizing.
  - Tightened calibration rules into hard rules: every fact has source + date or moves to GAPS; never invent quotes / numbers / events.
  - Post-meeting: vague commitments don't get promoted to followups.
