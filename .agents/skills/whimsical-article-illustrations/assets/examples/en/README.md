# English style-calibration examples

Reference renders for the **English** Inky style, generated by this skill (Nano Banana Pro, 16:9).
Use them the same way as the legacy `assets/examples/` — low-frequency calibration for line
density, white space, color restraint, and Inky's deadpan attitude. **Do not copy their
compositions, objects, or labels.** Each example is a *different* structure type so the set
demonstrates range, not one repeated layout.
