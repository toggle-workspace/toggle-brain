# Composition Patterns & Originality Rules

## Base structure types

Pick one structure. Don't mix too many.

### Workflow

Good for: input → process → output, content production, AI workflows, automation chains.

How: input on the left, the mascot or a weird machine processing in the middle, output on the right, orange arrows for the main flow.

### System fragment

Good for: information sources, filters, databases, renderers, a slice of an agent system.

How: draw only 3–5 core modules; the mascot handles one key action.

### Before / after

Good for: chaos/order, manual/automated, scattered/gathered, anxious/steady.

How: chaos on the left, steady on the right, orange arrow between. The character can be more exaggerated.

### Character state

Good for: user pain, creator state, too many tools, information anxiety, stuck → running.

How: 2–4 small states, one short label each.

### Concept metaphor

Good for: content factory, information warehouse, mental black box, workflow machine, automated daily report.

How: one big weird object or machine, a little input, one output. Make it memorable.

### Method layering

Good for: methodology frameworks, system hierarchy, capability stacks, layered content systems.

How: stacked boxes, not a formal pyramid; the mascot hauling bricks or building beside them.

### Map / route

Good for: idea → launch, user path, content handoff path, learning path.

How: one winding path, a few nodes, the mascot leading the line or walking.

### Mini comic panels

Good for: failure → success, the real process, a gripe, before/after usage.

How: 2–4 small scenes, one action per panel.

## Original-metaphor method

Reinvent the metaphor from the current article every time. Never lift an old image.

### Three steps

1. Turn the abstract concept into a physical action: stuck, dropped, gone heavy, sorted, settled, fermented, opened, folded, unpacked, flowing back.
2. Turn the system structure into one low-tech object: a broken machine, cardboard box, drawer, pipe, mailbox, weird dial, scale, well, ladder, odd workstation.
3. Give the mascot the action: not standing beside it, but stuck in the machine, pulling the wrong line, guarding a gate, hauling, patching, weighing, holding the ladder, taking notes, stuffing something into some weird contraption.

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, tangle of string, sluice gate, turntable, black box, hole punch, pasta press, clothesline, weird workstation.
- Use only 1–2 at a time. Don't pile them up.

### Mascot action pool

- Pull, haul, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, unpack, mark, recycle.
- The action must serve the core meaning. Don't be weird just to be weird.

## No-cloning rule

Don't default to opening or reproducing `assets/examples/`. Those images are for style calibration only — line density, white space, color restraint, mascot attitude.

Unless the user explicitly says "like this one / reproduce this composition / edit off this case," don't directly reuse these old compositions:

- Two breakpoints on a conveyor belt
- Mascot pulling a judgment lever inside a content machine
- Mascot as a funnel sorting traffic/trust/conversion
- Mascot slicing a material fish
- Mascot leading a handoff path
- Mascot pulling three layers of information sources
- Three mascots holding a megaphone / building a bridge / opening a door
- Mascot stamping a copy toolbox
- Mascot holding a sign over a common-pit path

Change the metaphor even for the same topic. "Handoff path" doesn't have to be a route — it can be the mascot hooking the content's tail onto a doorknob. "One-input-many-outputs" doesn't have to be a fish — it can be the mascot pressing one paper wad into several shapes.
