# discovery-synth — iterations

## v1 → v2
- v1 paraphrased themes without quotes. **Critique:** paraphrasing hides where bias enters. The user can't tell if a theme is real or if the model rephrased "kind of annoying" into "major pain point."
- **v2 change:** required verbatim quotes per theme.

## v2 → v3
- v2 still collapsed frequency and intensity into "lots of people care about X." **Critique:** 5 users mildly annoyed and 1 user threatening to churn are different signals — collapsing them lies to the founder.
- **v3 changes:**
  - Frequency and intensity reported separately and visibly.
  - Explicit sample bias call-out (warm intros, existing users, etc.).
  - Anti-themes section (what you expected but didn't hear).
  - "What this evidence does NOT support" — names the limits.
  - Theme inclusion bar (≥3 mentions OR 1 high-intensity).
  - Refusal to synth when material is too thin (< 3 substantive transcripts).
  - Sharpened small-N rule: < 5 = "hypothesis-generator, not findings."
