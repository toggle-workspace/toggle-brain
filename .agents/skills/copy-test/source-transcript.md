## The core idea

Harry Dry applies **three rules to every sentence** of ad copy. Each rule that fails is a "free no" (cut it); each that passes is a "free yes" (you're onto something).

1. **Can I visualize it?** — Close your eyes. Can you see it?
2. **Can I falsify it?** — Is it able to be proved true or false?
3. **Can nobody else say this?** — Is it bespoke to this brand, or could any competitor write the same line?

> **Good example (New Balance):** "New Balance, worn by supermodels in London and dads in Ohio." I think that is so good. It's true — supermodels have worn New Balance, dads in Ohio do wear them. And can nobody else say it? No — because a load of dads in Ohio aren't going to wear Prada, and a load of supermodels aren't really wearing Reebok. It's bespoke to New Balance. It's something they can only say.

## Why it matters

This is a fast, mechanical copy-test that maps onto any short marketing line - ad headlines, social/carousel copy, video VO, email subjects, landing-page hero lines. A line that passes all three is concrete, credible, and ownable. A line that fails any one is generic filler.
